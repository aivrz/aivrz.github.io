其他重要说明

各平台嵌入支持总览

平台可嵌入自动生成主要限制
YouTube支持支持上传者可关嵌入；年龄限制视频外站不可播
Vimeo支持支持上传者可限制嵌入域名（最多 50 个）
Bilibili支持支持需开启“允许嵌入”；移动端需自行适配
腾讯视频支持支持需开启“允许外链播放”；vid 区分大小写
优酷支持受限已停 HTML5 嵌入；需开启嵌入权限
爱奇艺支持不可靠自动拼地址常失效，建议用官方“通用代码”
抖音支持需 ID须“公开”；需 referrerpolicy；无自适应
TikTok支持支持仅公开视频；删除即失效
Facebook支持支持须用视频页链接（/videos/、/watch、/reel、fb.watch）
Dailymotion支持支持上传者可限域名；地区版权限制
微信视频号不支持不适用X-Frame-Options 禁止外站嵌套
1905 电影网不支持不适用无嵌入入口；地址带动态签名/防盗链
常见坑（生成前必读）：
• 腾讯视频“vid参数非法”：从“分享”复制的若是封面/合集页（v.qq.com/x/cover/<合集ID>.html），其 ID 不是视频 vid。请点开具体某一集，复制形如 v.qq.com/x/cover/<合集ID>/<vid>.html 或 v.qq.com/x/page/<vid>.html 的地址。
• Facebook 不生成：照片/主页/普通帖子链接不是视频页，本工具不会生成无效嵌入；请改用含 /videos/、/watch、/reel/ 或 fb.watch 的视频页链接。
可复用函数：同款逻辑已拆为独立文件，可直接集成到你的项目—— embed-generator.js（浏览器/Node 通用，VideoEmbedGen.generateEmbedCode(url, opts)）与 embed_generator.py（generate_embed_code(url, **opts)）。 返回结构含 platform_cn / supported / iframe / restrictions / note。
调研日期 2026-09-12。嵌入能否最终播放取决于视频上传者在各平台设置的隐私与版权开关，上线前请在目标域名实测。
